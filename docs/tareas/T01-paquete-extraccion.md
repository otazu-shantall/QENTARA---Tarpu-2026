# T01 · Paquete de extracción de datos de TARPU

La tarea completa y su carpeta de trabajo están en **[trabajo/T01-paquete-extraccion/](../../trabajo/T01-paquete-extraccion/README.md)**.

Resumen: un paquete de Python que, para cualquier punto, obtiene NASA POWER (19 variables), SoilGrids (WCS), FAO GAEZ, horas de luz (FAO-56) y MODIS (ORNL, en paralelo), y los guarda en el formato que lee el backend (original + normalizado + procedencia). No depende de nada pendiente.
