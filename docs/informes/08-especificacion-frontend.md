## Contenido consolidado

La documentación del frontend reúne alcance, recorrido, estados de interfaz, arquitectura, recursos visuales, requisitos de datos y criterios de aceptación. Guía, propuesta, decisiones y estado actual comparten las mismas definiciones.

El alcance vigente es una web para computadora, con sidebar izquierda, selección de parcela, evidencia e historial, comparación agrícola y consulta avanzada. El asistente inicial incluye chat, voz y burbujas de estado; el avatar humano es posterior. Los temas claro y oscuro permanecen abiertos.
